# Cue

Native tvOS media player (SwiftUI + UIKit), a GPLv3 fork of Orivio TV.
Content comes from Stremio add-ons (AIOStreams, debrid configured inside them).
Syncs with a **Nuvio** account (`Core/NuvioAccount/`, QR at first launch).
Bundle id `app.cue.tv`, URL scheme `cue://`, defaults keys `cue.*`.
Server-facing values (`nuvio_tvos_preferences`, `syncSource: "nuvio"`) must not change.

## How we work

- **Quick iterations; the user verifies on the TV.** For look and feel: make the
  change, one Debug build as the compile check, install on the sim, hand over
  with a short note. No screenshot rounds, no "let me verify" loops.
- Verify yourself only for behaviour or focus bugs, or when asked.
  Tool: `Tools/RemoteDriver/remote.sh "<keys>" [launch args]` presses real
  Siri Remote keys on the sim (`up/down/left/right/select/menu`, `hold`,
  `wait:<s>`, `shot:<name>`, `focus`, `<key>*<n>`; ~20 s per run).
- No test targets or UI test suites unless asked.
- **Unsure what the user means? Ask before building.** Many changes start as a
  discussion; when the user says "lets discuss", propose, don't build.
- Keep old code only when told to; otherwise remove what a change makes unused.
- No placeholders: things that belong together appear together.
- No speed/length multipliers for tuning: change the real values.
- Don't reintroduce anything listed under "Removed / rejected".
- Don't read `docs/*.md` unless the user asks — this file is the summary.
  Update this file when a decision changes.

## Build and run

```bash
xcodebuild -project Cue.xcodeproj -scheme Cue -configuration Debug \
  -destination 'platform=tvOS Simulator,id=2DF61D5F-2062-4C19-A952-EB24AC6EA7C3' \
  -derivedDataPath <scratchpad>/dd build 2>&1 | grep -E "error:|\*\* BUILD" | sort -u
xcrun simctl install 2DF61D5F-2062-4C19-A952-EB24AC6EA7C3 <dd>/Build/Products/Debug-appletvsimulator/Cue.app
xcrun simctl launch --terminate-running-process 2DF61D5F-2062-4C19-A952-EB24AC6EA7C3 app.cue.tv
```

- Debug only while iterating. Release only when the user measures fps.
- The project is generated by **xcodegen** from `project.yml`. Regenerating
  wipes Xcode GUI edits to the scheme: put launch args in `project.yml`
  (`schemes.Cue.run.commandLineArguments`), back up and diff the scheme after,
  tell the user. Prefer adding code to existing files over new files.
- `Cue/Secrets.swift` holds real keys and is gitignored — never commit it.
- Dev launch args: `-detailDemo -detailID tt…` (a show; add `-detailMovie`
  for a film — The Two Towers tt0167261 has a collection), `-detailDemoSeries [tt…]`
  (Breaking Bad default; Re:Zero tt5607616, One Piece tt0388629),
  `-transitionSlowMo` (4×), `-detailsHold`, `-holdMenuDemo`, `-browseDemo <person|genre|keyword|company|network> <tmdb id> <name>`,
  `-folderDemo`, `-moviesDemo`, `-homeFocusCollection`, `-cue.home.billboardAutoPage NO`.
- Render Lab (Settings → Performance) holds experiment switches
  (`PerformanceSettingsStore` / `RenderProbe.shared.flags`). Remove options
  once a decision is made.

## Design rules

- **Direction:** flat artwork, glass controls, one outline for focus. Calm,
  quick motion; a stable 60 fps beats fancy.
- The top bar hides by moving out the top and shows by moving back in
  (`GlassSidebar.hidden`, `Motion.move`) — everywhere; it is always in the
  view tree, disabled while hidden.
- **Glass only for what floats above the page** (top bar, hold menus, source
  picker, dropdowns, toasts); `liquidGlass(in:)`, always as a background.
  Everything in the page is flat (`FlatControl`). Exception: Details' buttons.
- No accent colours. Colour only for information (rating sources).
- Text: 24 pt regular is the base; 23–25 pt is the floor for TV text.
- Motion tokens (`Motion`): focus 0.3 s, move 0.35 s, present 0.45 s
  (no-bounce springs), fade 0.25 s. One press, one movement.
- Animate transforms and opacity only. Never alpha 0 on a focusable list
  (tvOS skips transparent views); hide cell contents or mask instead.

## Decided mechanisms

- **Home rows are UIKit**: native focus, scrolling off; we move rows with Core
  Animation in `didUpdateFocus`. Fixed box at the focus spot for most rows;
  Continue Watching / Saved for Later use the box at their card size.
  SwiftUI scroll versions were rejected (main-thread animation, lost targets).
  The focused row stays at its fixed spot near the top (not centred). The
  row below always starts the same gap (`peekGap`) below what the focused
  row draws — box info, captions, a panel's edge — so the peek varies, the
  gap doesn't; at least `minimumPeek` (70) of its cards always shows. The
  rows after it keep the same gap, so a row doesn't move again as it
  becomes the next one; the rows above too (below the cards of the one
  over them). Into a custom row (About) the rows only scroll as far as
  needed to show all of it, ending `customBottomGap` (60) above the
  screen's bottom — not at all if it already shows (`customContent`).
- **Billboard**: Featured row with invisible cells; picture in UIKit, text in
  SwiftUI above. Content = `BillboardPicks` (new episodes → "Because you
  watched" → trending) with a reason label above the logo. Compact text: logo,
  chips (status + 3 ratings), facts, tagline — no summary. Down as on
  Details: one move, the picture stays (blurring into the colours), the
  first row peeking 60 pt up the bottom edge under the billboard (its name
  above its darkened cards, the page dots on that line). Pages by itself every 5 s, stops at the last title.
  Left/Right: the picture crossfades drifting 16 pt the way you went
  (`StagePictureView.drift`); the text only crossfades, in place, as one
  block (`BillboardCrossfade` — run from inside the rows' host, else it
  only swapped; the text drifting looked restless). 0.35 s.
- **Details** uses the billboard's text and shade. Four buttons: Play,
  Library, Trailer, Summary (`text.alignleft`). Hold Play → straight to the
  source list. Summary opens the summary in place, in a glass panel
  (`DetailSummaryPanel`); Back closes it, focus back on the button.
  Play's pill says only "Play"; its caption (like the circles', only while
  focused) says which episode and the time left ("S2:E13  ·  46m left"),
  or "Finding a source…" while it searches.
- **Details' episode row**: under the billboard the episodes' cards peek
  60 pt up the bottom edge, darkened to 50 % (a black cover on the cards,
  not transparency — `FixedFocusRows.rigidPeek`). In the row, glass season
  buttons replace the row's name (moving focus; focusing one jumps the row
  there; Up from any card lands on the row's season); the season progress
  ("Season 2 • 3 of 13 watched", ticks) between the buttons and the cards.
  The season buttons and the map come up with the row, fading in (the
  Apple TV app's way). Up reverses it. (A shorter Details-only move,
  0.48 s, was tried and dropped: same time as Home's.)
  Tried and dropped: "Episodes ⌄" on the billboard instead of the peek;
  the row's name "‹ Season X ›" as the season control; the full progress
  on the billboard (also with Home's page-dots look); the show's logo over
  the season buttons (Apple TV app's way); progress inside each season
  button; the map above the buttons; the map under the episodes' captions.
- **Details' collection** (films; TMDB's collection — not Cue's Collections):
  the first row below the billboard, above More Like This, named "More from
  the … Collection". Fixed focus; the other parts in release order (the film
  itself left out), starting on the first; upcoming parts kept, parts
  without a picture left out. Details' peek never shows a row name (one
  title's page — Apple's rule); Home's does.
- **Details' Cast & Crew**: after More Like This. Moving focus, portraits
  (2:3, Search's poster size — `compactPosterHeight`, TMDB `h632`), name + role under each; creators /
  director first, then the cast (a show: `aggregate_credits`, most episodes
  first), about 20; no photo: initials; Select: the person's page; no menu.
- **Details' About**: the page's last row — a SwiftUI view in the rows
  (`FixedFocusRows.customRows`), not cards. `DetailAbout`: three columns of
  one width, each as long as it needs (room to the screen's bottom), left
  to right: genres, then tags (TMDB keywords), as chips shaped like the
  ratings' (filled, no outline; focused: white, dark text) — Select: that
  genre's / keyword's films or shows (`Route.genre`, `Route.keyword`,
  `TMDBBrowseView`); focus comes in on the first genre — then the summary,
  whole, under "SUMMARY"; then the facts, two to a line (when/how long/rated → who → where
  from → budget/box office; no network — it's in the row above), and every
  rating, wrapping (not pressable). Behind it a dark band (black 50 %, a clean
  edge, no fade) from just above its name to the bottom — the page's end.
  Never dimmed, in focus or not.
  Before it, **Network & Studios**: a moving-focus row of logos on
  light plates (`logoRowIDs`), Select: their titles.
- **Details' Cast & Crew**: after More Like This. Moving focus, portraits
  (2:3, Search's poster size — `compactPosterHeight`, TMDB `h632`), name + role under each; creators /
  director first, then the cast (a show: `aggregate_credits`, most episodes
  first), about 20; no photo: initials; Select: the person's page; no menu.
- **Details' About**: the page's last row — a SwiftUI view in the rows
  (`FixedFocusRows.customRows`), not cards. `DetailAbout`. To read: the
  summary in a fixed box (560 × 280, 8 lines, "…"; Select: all of it), beside
  it the facts in three columns — when/how long/rated → who → where from
  (language, country, original title) → budget/box office, empty ones close
  up — and one line with every rating (not pressable). Below, where to go:
  one line per kind, its name on the left — Genres (flat, slightly rounded
  tags: links, not the season buttons' capsules; TMDB genres → that genre's
  films or shows, `Route.genre`), later Tags (TMDB keywords, same look),
  Network & Studios (logos). Fixed height per title.
- **Browse pages** (Details' genres, tags, studios, networks, cast — one view,
  `TMDBBrowseView`): a kind label (GENRE / TAG / STUDIO / NETWORK / ACTOR…),
  the name, one facts line; a person has a portrait and a 3-line bio, a
  studio/network its logo on a light plate. Glass pills: Movies | Series
  (only where both exist; a genre maps to the other side's id) and one
  sort button (Popular / Top rated / Newest / A–Z; all but Popular also
  filter: votes ≥ 200 / out, ≥ 10 / ≥ 50) — a sort icon before its label, at the
  grid's right edge, apart from Movies | Series; TMDB's A–Z order kept whose list opens under it in
  Cue's glass menu panel (`HoldMenu.openDropdown`), the current one checked.
  Then the folder pages' grid itself (`FolderPosterGrid`, hosting Home's
  `FixedFocusDestinationCell`; six across). The header and its controls
  are one view in the grid's top inset and scroll with it (a header *cell*
  is recycled once scrolled off, its controls with it). Its height is fixed
  from the first frame (room for the controls kept). We choose where focus
  scrolls (`scrollViewWillEndDragging`): first line or controls → the page
  at its top, header whole; any other line only when it would come within
  60 pt of the screen's edge, then just enough to show it. Six posters to a
  line (Collections' grid: seven). A focus guide on the page (not in the
  scroll view — there it was never found), on while the page is at its
  top, takes Up from any column to the controls. Focus goes to the first title once the
  titles arrive; more pages as focus nears the end. (Tried and dropped:
  the header fixed above the grid — too much room lost; tvOS's own focus
  scroll plus resetting the page on the first line — it jumped.)
- **Details' More Like This**: fixed focus (Home's catalog style — the box
  tells the title). TMDB recommendations (else similar), 12 titles; titles
  not yet out or without any picture left out; watched films last.
- **Into Details** (`DetailTransition`, Core Animation overlay):
  - Fade everywhere: Home dims, the cover zooms (0.55 s), info fades in at 85 %. ~0.8 s.
  - The billboard uses the SAME transition as any card (Home dims, its
    picture zooms to Details', Details comes in; Back: fade + shrink).
    Tried and dropped (2026-10-11): an in-place transition from the
    billboard (Home's parts moving out, Details' rising in, reversed on
    Back) — every version needed workarounds (seams, doubled pictures).
  - Back: fade + shrink to 98 %.
  - Lessons: two identical layers crossfading dip (flicker); never draw text
    twice; one shared shade (`StageArt.shade(for:)`); Details keeps Home's
    picture and logo; `CATransaction.flush()` or CA starts a runloop late.
- **Card edge**: every card (posters, the fixed box, Continue Watching,
  episodes, Saved for Later, cast, studios, Search's banner) has a printed
  card's light frame — a 2 pt line, white 30 %, inside its corner
  (`FixedFocusCardEdge.rim`). Focus keeps its own outline outside the card.
- **Hold menus**: all are Cue's own `HoldMenu` (not the system's: it ate the
  next press). Glass panel beside the card; pressed −3 %, open +2 %.
- **Sources**: no sorting or filtering — the add-ons' order (AIOStreams ranks).
  Play takes the first link. 5-min cache. No remembered source.
- **Series status chip**: AIRING / RETURNING / ENDED [year]
  (`FixedFocusShowInfo.status`).
- **Loading**: title record on disk, stale-while-revalidate; launch curtain
  with a time cap; background preload queue; Details built with its data
  (no late updates).
- **Collections**: one panel row per collection on Home. A folder page is
  Home's rows (`FixedFocusRows`): a catalog per row, all its titles, the
  focused row at Home's spot, the next peeking; the folder's name and
  subtitle above the first row. A one-catalog folder opens the poster grid instead (the
  browse pages' grid, with the folder's cover). Every collection shows this
  way, whatever its Nuvio `viewMode` (the value isn't touched). The old
  two-lines-per-catalog blocks, tabs and "See All" pages are gone.
  The header is the rows' `pageHeader`: it moves up with the first row in
  the rows' own animation. Movies / Series show the collections too, only
  folders with sources of that kind (`CollectionSourceDTO.kind`; unknown
  counts), at Home's place; a folder opened there shows only that type
  (`Route.folder(type:)`).

## Removed / rejected (don't bring back)

- Removed features: cloud library, Plex/Jellyfin, Live TV/M3U, JS plugins,
  in-app debrid/TorrServer, themes/accent palettes, external players,
  Trakt/SIMKL accounts (public Trakt lists stay), Stremio account.
- Ask before touching the Nuvio sync.
- Rejected looks: glows, underlines, dimming the screen for the top bar or
  hold menus, bouncy springs, "through colour" / cascade /
  wipe transitions, billboard strip above the rows; on the billboard's
  Left/Right: a full page scroll (too much movement), the text's parts
  staggered (cascade).
